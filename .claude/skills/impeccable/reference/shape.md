# Shape the requested work

Follow `AGENTS.md`. Inspect the actual product and existing implementation to establish the audience, task, content, states, constraints, and visual conventions. Infer routine choices from the request and code; ask only when information is required to proceed.

Implement the requested behavior, then verify it in the running surface with relevant accessibility, interaction, and responsive checks. Explain important decisions inline in the response or pull request. Do not create a design brief or stop at a proposal when implementation was requested.
