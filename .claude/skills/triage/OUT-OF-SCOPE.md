# Prior rejection decisions

Follow `AGENTS.md`. Search the HoBo Linear team for prior rejected requests by concept and inspect the decision and reasoning before treating a new request as a duplicate.

When the user authorizes triage and an enhancement is rejected, record the decision and relevant issue links in Linear. Do not create repository files for triage notes, rejection lists, plans, or design records. An already implemented feature is not a rejection; point to the implementation instead.
