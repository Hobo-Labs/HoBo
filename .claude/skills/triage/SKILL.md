# Triage

Follow `AGENTS.md` and the user's request. Inspect the issue or pull request and its relevant code, check whether the behavior already exists, and reproduce defects when possible. Report evidence and material uncertainty clearly.

When implementation is requested, fix the behavior and run appropriate checks instead of creating an agent brief, design document, or backlog. Only change tracker state or send comments when the user explicitly requests those actions. Keep decisions in the response or the authorized pull request.
