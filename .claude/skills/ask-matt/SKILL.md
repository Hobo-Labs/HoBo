# Choose a workflow

Follow `AGENTS.md`. Use `repo` for repository implementation, `sdlc` for delivery, `gh-stack` for dependent pull requests, and `tdd` when behavior needs a regression test. Apply domain-modeling guidance directly to code when naming or contracts need work. Complete the requested work instead of creating planning documents or issue backlogs.
