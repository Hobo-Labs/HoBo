# Project proof reference

Existing project proofs live under `src/draft/projects/<slug>`. Complete behavior in the packages that own shared contracts, update integrations, and remove obsolete proofs and references.

Run the affected production and integration checks. Document setup and usage only for behavior that exists. Capture evidence from a real run when needed; do not create ADRs, planning documents, synthetic ledgers, or placeholder projects.
