# Prototype

Follow `AGENTS.md`. Identify the question from the request and existing behavior. Use [LOGIC.md](LOGIC.md) for state and logic work or [UI.md](UI.md) for interface work.

Build the smallest runnable implementation that answers the question. Exercise meaningful behavior and preserve the validated result in the owning code when implementation is requested. Remove disposable exploration before finishing. Explain the result in the response or pull request; do not create planning files, notes, placeholders, or explanatory code comments.
