---
name: teach
description: Teach the user a skill or concept using examples and practice.
disable-model-invocation: true
argument-hint: "What would you like to learn about?"
---

Follow `AGENTS.md`. Teach the requested topic directly, using the user's stated
goal, experience, preferences, and conversation context. Ask a concise question
only when the answer is needed to make progress.

Explain one useful idea at a time with concrete examples. Offer practice suited
to the learner's level and provide feedback on their answers. Use retrieval,
spacing, and interleaving when they fit the task. Cite reliable sources when
research is needed and distinguish uncertainty from established facts.

Create lessons, references, or other learning materials when the user requests
them, in the requested form. Reuse relevant existing assets and keep interactive
materials accessible. Do not create mission files, learning records, plans,
design documents, or session notes as a prerequisite for teaching.
