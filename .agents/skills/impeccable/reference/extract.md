# Extract reusable UI

Follow `AGENTS.md`. Inspect the existing component library, shared UI, tokens,
and naming conventions. Choose locations using the repository's established
structure; ask only when a missing decision blocks the requested work.

Extract repeated components, tokens, and interaction patterns that share the
same purpose. Preserve meaningful differences instead of forcing unrelated
uses into a generic abstraction. Implement clear types, accessible controls,
keyboard behavior, focus management, and appropriate variants.

Migrate the affected uses, remove dead code, and verify visual and functional
behavior. Update existing user-facing component examples or usage documentation
when needed. Do not create design documents, planning files, or review backlogs.
